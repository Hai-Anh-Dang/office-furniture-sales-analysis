# Data

The inspected working model contains order, customer, product, payment, and shipping tables. Its recorded evidence covers 24 September 2023 to 23 September 2024.

The original dataset publisher, source URL, and redistribution terms have not been confirmed. Raw records and sample customer data are therefore not included in this repository.

This project estimates order value from quantity multiplied by the current product-table unit price. Currency and the meaning of source cost fields are unspecified. The analysis does not calculate revenue or margin from those fields.
